# Data directory

| Path | Content |
|---|---|
| `data/raw/household_power_consumption.txt` | **Original, unmodified** dataset (semicolon separated, `?` = missing, ~133 MB, 2,075,259 data rows). |
| `data/raw/archive_7.zip` | Optional: the originally supplied archive (the notebook can extract the text file from any `*.zip` in `data/raw/`). |
| `data/processed/hourly_observed.csv` | Hourly aggregation (observed values only, plus `n_obs` and `is_valid_hour`). Generated by the notebook. |
| `data/processed/hourly_inputs_causal_filled.csv` | Hourly data with short gaps (≤ 3 h) causally forward-filled for *model inputs*, plus a `target_imputed` flag. Generated by the notebook. |

## Raw-data preservation
The notebook never writes to `data/raw/`. It records the file's SHA-256 when loading and asserts at the end that it is unchanged. All cleaning happens in memory; derived data go to `data/processed/`.

## Getting the data
The file is **not committed** (size; see `.gitignore`). Place the original `household_power_consumption.txt` (extracted from the supplied `archive (7).zip`) in `data/raw/`, or put the zip in `data/raw/` and run the notebook, which extracts the expected member. No download link is provided here because none was supplied with the assignment.

## Columns
`Date` (d/m/Y), `Time` (H:M:S), `Global_active_power`, `Global_reactive_power`, `Voltage`, `Global_intensity`, `Sub_metering_1`, `Sub_metering_2`, `Sub_metering_3`.
Units (kW, V, A, Wh per minute for sub-metering) are **not stated in the file**; they follow the public documentation of the well-known UCI "Individual household electric power consumption" dataset (provenance as commonly documented; please verify against your source before citing).

Check the licence/terms of the original source before redistributing the raw file; derived hourly files are small and generated by the notebook.
