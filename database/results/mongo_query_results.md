## M2_date_range_summary

Summary of all valid hours between 2008-01-01 and 2008-01-31 (range scan on the compound index, then $group).

`db.hourly_readings.aggregate(pipeline)`

```json
[
  {
    "$match": {
      "household_id": "hh_001",
      "timestamp": {
        "$gte": {
          "$date": "2008-01-01T00:00:00Z"
        },
        "$lt": {
          "$date": "2008-02-01T00:00:00Z"
        }
      },
      "quality.is_valid_hour": true
    }
  },
  {
    "$group": {
      "_id": null,
      "valid_hours": {
        "$sum": 1
      },
      "energy_kwh": {
        "$sum": "$measurements.global_active_power_kw"
      },
      "avg_kw": {
        "$avg": "$measurements.global_active_power_kw"
      },
      "peak_kw": {
        "$max": "$measurements.global_active_power_kw"
      },
      "avg_voltage": {
        "$avg": "$measurements.voltage_v"
      }
    }
  },
  {
    "$project": {
      "_id": 0,
      "valid_hours": "$valid_hours",
      "energy_kwh": {
        "$round": [
          "$energy_kwh",
          1
        ]
      },
      "avg_kw": {
        "$round": [
          "$avg_kw",
          3
        ]
      },
      "peak_kw": {
        "$round": [
          "$peak_kw",
          3
        ]
      },
      "avg_voltage": {
        "$round": [
          "$avg_voltage",
          1
        ]
      }
    }
  }
]
```

## M4_avg_load_by_hour_weekday_vs_weekend

Average daily load profile for weekdays vs weekends (group by hour and is_weekend).

`db.hourly_readings.aggregate(pipeline)`

```json
[
  {
    "$match": {
      "quality.is_valid_hour": true
    }
  },
  {
    "$group": {
      "_id": {
        "hour": "$calendar.hour",
        "weekend": "$calendar.is_weekend"
      },
      "avg_kw": {
        "$avg": "$measurements.global_active_power_kw"
      }
    }
  },
  {
    "$group": {
      "_id": "$_id.hour",
      "pairs": {
        "$push": {
          "k": {
            "$cond": [
              "$_id.weekend",
              "avg_kw_weekend",
              "avg_kw_weekday"
            ]
          },
          "v": {
            "$round": [
              "$avg_kw",
              3
            ]
          }
        }
      }
    }
  },
  {
    "$sort": {
      "_id": 1
    }
  },
  {
    "$project": {
      "_id": 0,
      "hour_of_day": "$_id",
      "profile": {
        "$arrayToObject": "$pairs"
      }
    }
  },
  {
    "$project": {
      "hour_of_day": 1,
      "avg_kw_weekday": "$profile.avg_kw_weekday",
      "avg_kw_weekend": "$profile.avg_kw_weekend"
    }
  }
]
```

## M5_energy_share_by_circuit

Share of total energy per circuit, summing the fields of the embedded sub_metering_wh document.

`db.hourly_readings.aggregate(pipeline)`

```json
[
  {
    "$match": {
      "quality.is_valid_hour": true
    }
  },
  {
    "$group": {
      "_id": null,
      "Kitchen": {
        "$sum": "$sub_metering_wh.kitchen"
      },
      "Laundry room": {
        "$sum": "$sub_metering_wh.laundry_room"
      },
      "Water heater & A/C": {
        "$sum": "$sub_metering_wh.water_heater_ac"
      },
      "Other (not sub-metered)": {
        "$sum": "$sub_metering_wh.other"
      }
    }
  },
  {
    "$project": {
      "_id": 0,
      "circuits": {
        "$objectToArray": "$$ROOT"
      }
    }
  },
  {
    "$unwind": "$circuits"
  },
  {
    "$match": {
      "circuits.k": {
        "$ne": "_id"
      }
    }
  },
  {
    "$group": {
      "_id": null,
      "rows": {
        "$push": {
          "circuit": "$circuits.k",
          "wh": "$circuits.v"
        }
      },
      "total": {
        "$sum": "$circuits.v"
      }
    }
  },
  {
    "$unwind": "$rows"
  },
  {
    "$project": {
      "_id": 0,
      "circuit": "$rows.circuit",
      "total_kwh": {
        "$round": [
          {
            "$divide": [
              "$rows.wh",
              1000
            ]
          },
          1
        ]
      },
      "pct_of_total": {
        "$round": [
          {
            "$multiply": [
              {
                "$divide": [
                  "$rows.wh",
                  "$total"
                ]
              },
              100
            ]
          },
          2
        ]
      }
    }
  },
  {
    "$sort": {
      "total_kwh": -1
    }
  }
]
```

Result (4 documents):

| circuit                 |   total_kwh |   pct_of_total |
|:------------------------|------------:|---------------:|
| Other (not sub-metered) |     19085.6 |          51.2  |
| Water heater & A/C      |     13233.5 |          35.5  |
| Laundry room            |      2661   |           7.14 |
| Kitchen                 |      2299.4 |           6.17 |

## M8_missing_hours_per_year

Data-quality query: how many invalid (missing) hours per year.

`db.hourly_readings.aggregate(pipeline)`

```json
[
  {
    "$group": {
      "_id": "$calendar.year",
      "hours": {
        "$sum": 1
      },
      "invalid_hours": {
        "$sum": {
          "$cond": [
            "$quality.is_valid_hour",
            0,
            1
          ]
        }
      }
    }
  },
  {
    "$sort": {
      "_id": 1
    }
  },
  {
    "$project": {
      "_id": 0,
      "year": "$_id",
      "hours": "$hours",
      "invalid_hours": "$invalid_hours",
      "pct_invalid": {
        "$round": [
          {
            "$multiply": [
              {
                "$divide": [
                  "$invalid_hours",
                  "$hours"
                ]
              },
              100
            ]
          },
          2
        ]
      }
    }
  }
]
```

Result (5 documents):

|   2006 |     367 |               1 |          0.27 |
|   2007 |    8760 |              67 |          0.76 |

|   2009 |    8760 |              73 |          0.83 |
